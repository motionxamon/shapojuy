# Shapojuy — руководство на русском

Shapojuy — компактная ScriptUI-панель для работы с векторными слоями и Shape Layers в Adobe After Effects 2026.

[English guide](README_EN.md) · [Главная](README.md) · [Последний релиз](https://github.com/motionxamon/shapojuy/releases/latest)

## Возможности

- Конвертация AI, EPS, PDF и SVG в нативные Shape Layers.
- Конвертация вектора с немедленным Explode.
- Массовый Explode нескольких выделенных Shape Layers.
- Пропуск пустых групп, появившихся после импорта из Illustrator.
- Возможность сохранять управляющие Paths без Fill и Stroke.
- Merge нескольких Shape Layers с сохранением визуального положения.
- Поддержка Shape Layers, присоединённых к двумерным Null-объектам.
- Три системы координат для Merge.
- Перенос Transform-анимации по исходным ключам или покадрово.
- Очистка пустых вложенных групп.
- Нормализация стандартных названий вроде `Group 1` и защита от одинаковых имён.
- Единый Undo для каждой операции.

## Как скачать

1. Откройте страницу [Releases](https://github.com/motionxamon/shapojuy/releases).
2. Выберите последний релиз.
3. В блоке **Assets** скачайте файл `Shapojuy.jsx`.

Также исходный файл можно скачать напрямую из репозитория, но для обычной установки рекомендуется версия из Releases.

## Установка на macOS

1. Закройте After Effects.
2. Скопируйте `Shapojuy.jsx` в папку:

   ```text
   /Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/
   ```

3. Запустите After Effects.
4. Откройте `Window → Shapojuy`.
5. Перетащите панель в нужную часть интерфейса и пристыкуйте её.
6. Сохраните Workspace, если After Effects не запомнил расположение автоматически.

Для записи в папку приложения macOS может запросить пароль администратора.

## Установка на Windows

1. Закройте After Effects.
2. Скопируйте `Shapojuy.jsx` в папку:

   ```text
   C:\Program Files\Adobe\Adobe After Effects 2026\Support Files\Scripts\ScriptUI Panels\
   ```

3. Запустите After Effects.
4. Откройте `Window → Shapojuy`.
5. Пристыкуйте панель и сохраните Workspace.

Для записи в `Program Files` могут потребоваться права администратора.

## Интерфейс

Панель по умолчанию занимает одну компактную строку.

| Кнопка | Действие |
| --- | --- |
| `V→S` | Конвертировать выделенные векторные слои в Shape Layers |
| `V→X` | Конвертировать вектор и сразу выполнить Explode |
| `X` | Разбить выделенные Shape Layers на отдельные слои |
| `M` | Объединить выделенные Shape Layers |
| `C` | Очистить пустые Illustrator-группы |
| `⚙` | Показать или скрыть настройки |

При наведении на кнопку After Effects показывает полную подсказку.

## Vector → Shapes (`V→S`)

1. Поместите AI, EPS, PDF или SVG в композицию.
2. Выделите один или несколько векторных слоёв на Timeline.
3. Нажмите `V→S`.

Shapojuy последовательно запускает штатную команду After Effects **Create Shapes from Vector Layer** для каждого выделенного слоя. Созданные Shape Layers остаются выделенными.

## Vector → Explode (`V→X`)

1. Выделите векторные слои.
2. Выберите нужные настройки Source, Anchor и фильтрации Paths.
3. Нажмите `V→X`.

Скрипт конвертирует каждый векторный слой, затем разбивает созданный Shape Layer на отдельные непустые слои.

## Explode (`X`)

1. Выделите один или несколько Shape Layers.
2. Нажмите `X`.

Каждая верхнеуровневая группа с геометрией превращается в отдельный Shape Layer. Общие Fill, Stroke и операторы верхнего уровня сохраняются. Пустые результаты автоматически удаляются.

Если включено **Explode selected top-level groups only**, обрабатываются только группы, выделенные внутри `Contents`.

## Merge (`M`)

1. Выделите минимум два Shape Layer.
2. Выберите режим координат и анимации.
3. Нажмите `M`.

Содержимое каждого исходного слоя помещается в отдельную внутреннюю Shape Group. Для неё рассчитываются Position, Scale, Rotation, Skew и Opacity относительно итогового слоя.

### Merge coordinates

- `Comp Space` — результат создаётся в координатах композиции. Самый универсальный режим.
- `Common Parent` — общий двумерный родитель сохраняется, если он одинаков у всех выбранных слоёв.
- `First Layer` — система координат верхнего/первого слоя используется для результата.

### Merge animation

- `Off` — сохраняется положение только на текущем кадре.
- `Key Times` — Transform и parent-цепочка измеряются на существующих ключевых кадрах.
- `Every Frame` — трансформация измеряется на каждом кадре. Это самый точный режим для сложной анимации, но он создаёт много ключей.

## Clean (`C`)

1. Выделите Shape Layers.
2. Нажмите `C`.

Clean рекурсивно удаляет пустые вложенные группы, находит пустые слои и при включённой нормализации исправляет стандартные имена.

## Настройки Source

- `Keep` — оставить исходные слои без изменений.
- `Disable` — выключить исходники после успешной операции.
- `Archive` — выключить исходники, включить Shy и добавить комментарий `Shapojuy archived source`.
- `Delete` — удалить исходники после успешной операции.

Для первых тестов рекомендуется `Disable` или `Archive`.

## Настройки Anchor

- `Keep` — не менять Anchor Point.
- `Visual Center` — поставить Anchor Point в центр видимой графики, не сдвигая изображение.
- `Comp` — поставить Anchor Point в центр композиции, не сдвигая изображение.

Автоматическая коррекция Anchor не применяется к 3D, анимированным и separated-dimension трансформациям.

## Дополнительные настройки

- `Explode selected top-level groups only` — Explode только выделенных групп верхнего уровня.
- `Keep control Paths without Fill/Stroke` — не считать невидимые управляющие Paths мусором.
- `Normalize names and avoid duplicates` — исправлять стандартные имена и предотвращать совпадения.
- `Show confirmation before destructive operations` — показывать предварительный отчёт перед удалением или изменением исходников.

## Ограничения

- Merge поддерживает только двумерные Shape Layers и двумерные parent-цепочки.
- 3D-слои и 3D-родители намеренно блокируются.
- Effects, Masks, Layer Styles и Track Mattes невозможно независимо перенести внутрь отдельных Shape Groups. Перед Merge скрипт предупреждает об их наличии.
- Режим `Key Times` может отличаться между ключами при сочетании нескольких анимированных трансформаций. Для максимального совпадения используйте `Every Frame`.
- При конвертации вектора остаются ограничения штатной команды After Effects для некоторых градиентов и неподдерживаемых возможностей Illustrator.

## История проекта

Shapojuy — самостоятельная реализация рабочего процесса Explode/Merge, популяризированного `zl_ExplodeShapeLayers`. Исходный код этого скрипта не включён и не распространяется в данном репозитории.
